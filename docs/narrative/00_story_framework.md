## 一、世界气质

故事发生在**AI 自动化浪潮的"第二个早晨"**——不是恐慌的第一夜，也不是已经被遗忘的第十年，而是那个潮水刚退去的时刻：人们还没完全适应，但已经开始谋生。

这个小城不大，有学校、工厂区、居民楼、夜市和一条街灯不那么亮的后街。城里有人还在跑外卖，有人学会了给算法打工，有人悄悄保留着一些"没用的"技能，有人来了又走。

不写反乌托邦宣言。**背景只通过具体的人、具体的事、具体的一杯水果饮品渗出来。**

## 二、主角身份（备忘，忌直说）

曾在与 AI 系统工程化相关的高压岗位卖命多年——接触过硬件，做过流水线调度、数据管线一类的脏活，最后以"优化"为由被自己参与搭建的那套系统替代。心灰意冷，回到家乡，成了鲜果铺的临时工。

**宣讲禁止**。以下方式可用：
- 职业条件反射（下意识估算出品效率，看到设备故障先想排查顺序而不是叫人）
- 单独的"内心"节点，极短，用身体细节（手、呼吸、眼前的一个东西），不说结论
- 与镜像客之间的侧面对话（主角从不主动解释自己的过去）

## 三、三幕结构（10 天）

```
序章
  第一单：柠檬水 / 学生 / 二十来秒
  柚子托付，街灯亮起

第一幕  Day 1–3  ｢落脚｣
  学规矩，认第一批脸
  第一个 VIP 出现（日间，轻量级）
  节奏从"新人"过渡到"能独当一面"

第二幕  Day 4–8  ｢生根｣
  VIP 线逐步展开，人物开始互相连接
  第一次房租压力（数字）
  镜像客登场（夜间，慢热）
  老板的第一封信（荒谬但有用）
  店铺危机开始酝酿

  危机锚点（Day 6–7）
    ——房东涨租 + 设备集体罢工，二者同时到来
    ——每个常客用自己的方式帮忙兜住（不是英雄式拯救）
    ——柚子第一次正面承认"店差点没了"

第三幕  Day 9–10  ｢开花｣
  各条 VIP 线收口（不必全部大圆满，允许悬而未决的）
  最后一夜，所有人在店里
  举杯——老板的位置：空椅 / 一纸贺词 / 那个你不确定是不是他的人
```

**终点的情感目标：** 不是"一切都好了"，而是"这里值得待下去，哪怕外面还是那个样子"。

## 四、店铺危机细节（第二幕锚点）

危机不是一个人造成的，也不是一个人解决的：

- **房东**：涨租通知，数字是真实的（不是抽象的"压力"），可以和 VIP 的某条线联动（比如 VIP 知道房东的联系方式，或者帮忙查到了什么）
- **设备**：冷柜彻底罢工（序章里"敲两下"的那台终于撑不住了）、榨汁机二次阵亡
- **解决方式**：各客人以各自的能力帮忙——有人出钱，有人出人脉，有人只是来喝了一杯然后什么都没说但第二天危机消了

老板这时候会送来一封信。措辞一本正经，建议"多备一台榨汁机"或者别的完全不着调的东西，但信封里夹着一样真正有用的东西（现金/联系方式/某个信息）。

## 五、主角过去渗出的节点设计

| 时机 | 渗出方式 |
|------|---------|
| 设备故障 | 下意识说出故障诊断步骤，柚子侧目 |
| 面对镜像客（阿往） | 不解释，只是听；内心节点一刀，极短 |
| 第一次看账本 | 手指在纸上停了一下——不是不会算，是太久没为自己的事情算了 |
| 危机过后，关灯时 | 系统旁白一句收束，类似序章的街灯那句 |
| 夜班第一次（Wings of Silence 时机） | 柚子不在，主角独自在店里，接近自白但仍然没说破 |

## 六、叙事节奏约定（执行层）

- **旁白**：巨响/动作/环境变化，不做心理分析
- **内心**：每章 0–1 刀，用身体细节，不说结论
- **系统**：每天结尾一句，散文感，过渡到结算画面
- **订单卡**：`html` 卡片式，三要素：品名 / 人物特征 / 时间感
- **老板信件**：每封独立节点，措辞"圣旨感"，荒谬+真用，不超过 4 句话
- **成绩分支**：good/ok/bad 三档，每档不超过 4 条，**像嘴碎不像金句**
