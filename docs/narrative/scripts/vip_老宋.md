# 老宋 · 首次登场对白草稿

> 曲目：*Qua Vadis*（M2U，「你往何处去」，160 BPM）  
> 场景：Day 6，夜晚，他来得很晚，坐在角落。  
> 目标：让人记住他的等待姿态——像在等一个从来不来的人，以及「我们公司」那三个字。

## 执行注记

- **「需要等一下才能好的」**：他需要一个理由多坐一会儿，这就是他点单的逻辑。不要让玩家一眼看穿，让这件事在下一次访问时自然浮出。
- **看向门口**：那个方向什么都没有，但他看的样子像在等人。那个人从来不来——这是他的某种习惯，或者某种练习。
- **「我们公司」**：他说了六年了，改不过来。说出口之后他自己意识到了，选择了一个安全的方向解释。但「我们公司」装着的不只是会议。
- **不评价味道**：他只是喝了。不是礼貌，是他来这里不是为了品尝什么。
- **第一次登场禁止出现**：他发出去几百封裁员通知、他自己收到那封邮件、他看了三秒直接关掉没有回复。那些是后面的事。这次你只看见一个来得很晚、不急着走的男人。
