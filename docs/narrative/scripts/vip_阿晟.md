## 执行注记

- **那行硬币是这个人的全部。** 不需要解释，不需要主角的内心旁白去点破。他自己说了"有实感"，就够了。
- 他的第一句话是需求，不是招呼——这个人不寒暄。
- 「失准」那个停顿：他在找最精确的词，不是在犹豫。动作和语气要能让人感觉出来这两件事不一样。
- 手机屏朝下：他在等一个重要的电话，但他不让它主导这个空间。这个细节不必说明，做出来就行。
- 内心节点「（……）」：此处留白优于任何内心旁白。主角注意到了，但不知道说什么。沉默本身就是反应。
- **第一次登场禁止出现：AI、算法、裁员、投诉、申诉。** 那些是后面的事。
