# 月叔 · 首次登场对白草稿

> 曲目：*Lunatic Sky*（M2U，Melodic Trance，160 BPM）  
> 场景：Day 10，深夜，夜班保安结束一段巡逻，顺路买菠萝汁。  
> 目标：让人记住他仰头看那一小片天，还有那个口袋里鼓着的小本子。

## 执行注记

- **走路很轻**：他习惯安静地在场，不惊动人。这是夜班保安的职业质感，也是他这个人的质感。
- **那一小片天**：他专门往上看。不需要解释这是为什么，玩家会懂，或者会在第二次访问时懂。
- **小本子**：里面记的是流星——日期、方向、持续几秒，有时有备注。这次玩家看不见里面，只看见他写了什么放回去。
- **「今晚有云」**：他看了，他知道，他记下来了。这件事不需要解释是好消息还是坏消息，它就是一个事实。
- **「甜的，晚上提神」**：他说酸的太清醒，甜的让他在对的地方走神——这句话是第二次访问时说的。这次他只说「甜的，常温就好」。
- **第一次登场禁止出现**：四年材料工程、晶格结构和星星的类比、那条「太亮，没有名字，已经忘了」的记录。那些是后面的事。
