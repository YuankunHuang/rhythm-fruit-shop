# 无名 · 首次登场对白草稿

> 曲目：*Ineffabilis*（M2U & Gentlestick，「不可名状」，160 BPM）  
> 场景：Day 9，夜晚，他来，他走。  
> 目标：让人记住他多站的那一会儿。

---

## 脚本

```json
[
  { "speaker": "", "text": "夜里来了一个人。普通，就是普通。" },
  { "speaker": "无名", "text": "草莓汁。" },
  { "speaker": "你", "text": "来了。" }
]
```

---

## 执行注记

- **三行**：这是他第一次出现该有的全部。来，点单，等。不要加任何「气氛渲染」的叙事。
- **「普通，就是普通」**：他不特别，这是他的重点。他能在这里存在，是因为这里允许普通。
- **不要解释他是谁或者为什么来**：玩家在这里不应该知道任何关于他的事。他只是一个点了草莓汁的人。
- **服务后的「多站了一会儿」**：那个停留是真实的，但不要描述他的表情、眼神或者内心。只是：他多站了一会儿。
- **对白越少越好**：写完之后如果可以再少几个字，就再少。
