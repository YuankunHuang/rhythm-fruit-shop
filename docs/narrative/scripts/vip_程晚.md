# 程晚 · 首次登场对白草稿

> 曲目：*Drama*（Diana Boncheva，电子舞曲，~134 BPM）  
> 场景：Day 3，黄昏，演出散场后。  
> 目标：让人记住她坐下来之前看椅子那一眼，以及"甜的感觉像在演戏"这句话。

## 执行注记

- **坐下来之前看椅子**：职业习惯，确认椅子稳不稳、高不高——她在台上不允许失控，这个习惯延续到生活里。不要解释，只做出来。
- **「甜的感觉像在演戏」**：不是在批评甜这件事本身，是她的某种审美训练——太容易给出的情绪让她不信任。这句话说出来像顺嘴，但背后有很长的历史。
- **「在某个版本里」**：她不确定自己说的话是真实还是表演，用这个短语给自己留了余地。重复出现的口癖——不要解释，让玩家自己感觉。
- **脊背那一次放松**：她从台上的「模式」切换到台下的「模式」，用一个微小的动作做标记。
- **第一次登场禁止出现**：AI 生成剧本、被删台词、观众鼓掌的故事。那是第二次的事。这次她只是个演完了来买一杯酸冰沙的人。
