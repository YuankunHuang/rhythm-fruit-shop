# 顾薇 · 首次登场对白草稿

> 曲目：*Purple Passion*（Diana Boncheva，电子舞曲，168 BPM）  
> 场景：Day 6，黄昏，她带着一个旧手绘本。  
> 目标：让人记住那个手绘本里大部分空白的页，以及她问「这个配色感觉怎样」。

## 执行注记

- **手绘本**：封面磨得很旧，但里面大部分页是空白的——画了一半就停了。玩家这次看不到这件事，只是看见她在用它。
- **在空中虚比那个形状**：她思维里有一个具体的东西，但她不解释那个形状是什么。这是她的习惯，不是在卖关子。
- **「谢，比想象中有用」**：她真的觉得这个很有用，因为她对别人的配色判断比对自己的更自信。这是她的矛盾点的第一次微弱出现，但不要点破。
- **「太顺滑了反而不安心」**：和阿晟的「最稠那种」在表面上相似，但理由不同。阿晟要阻力是因为需要事物有质地；她要颗粒是因为太完美的东西让她不信任自己的感觉。
- **第一次登场禁止出现**：「AI 润图」外包、恨这件事但靠它活着、那本空了大半的手绘本里究竟画过什么。那些是后面的事。
