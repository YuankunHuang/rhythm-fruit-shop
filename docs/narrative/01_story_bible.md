# 《节奏鲜果铺》写手参考手册（Story Bible）

> 写手工作文档。世界设定与故事总览见 `STORY.md`，人物详卡见 `02_core_cast.md` / `03_vip_characters.md`，对白执行规范见 `05_writing_guide.md`，Track Event 机制见 `04_track_event_design.md`。

---

## 一、世界约束（快速核对）

- **时代**：AI 自动化「第二个早晨」——调整期，不是崩溃期
- **禁止**：反乌托邦宣言、英雄式叙事、AI 作为反派、角色自我解释处境
- **背景渗出方式**：通过角色说的「别的事」透出来，绝不直接陈述

---

## 二、三幕结构（10 天）

```
序章
  柠檬水 / 学生 / 二十来秒
  柚子托付，街灯亮起

第一幕  Day 1–3  「落脚」
  学规矩，认第一批脸
  第一个 VIP 出现（日间，轻量级）
  节奏：新人 → 能独当一面

第二幕  Day 4–8  「生根」
  VIP 线逐步展开，人物开始互相连接
  第一次房租压力（具体数字）
  镜像客（老宋）登场——夜间，慢热
  老板第一封信

  危机锚点（Day 6–7）
    ——房东涨租 + 设备集体罢工，二者同时
    ——每个常客用自己的方式兜住，不是英雄式拯救
    ——柚子第一次正面说「我以为这次真的完了」

第三幕  Day 9–10  「开花」
  各条 VIP 线收口（允许悬而未决）
  最后一夜，所有人在店里
  举杯——老板的位置不被解释，玩家自行判断
```

**情感终点**：不是「一切都好了」，是「这里值得待下去，哪怕外面还是那个样子」。

## 三、主角的情感弧线

主角的过去不被说出，但弧线是真实的——从「执行状态」到「重新在场」。

| 阶段 | 情感状态 | 标志性行为 |
|------|---------|-----------|
| 序章–Day 3 | 执行状态：做事，不感受 | 职业反射先于情绪；不主动说任何事 |
| Day 4–6 | 轻微的「在意」萌发 | 注意到某人第二次来；某杯东西打得比上次好 |
| Day 6–7（危机） | 第一次真正的焦虑——不是为自己 | 为这家店、为这些人，而不是为自己的处境 |
| Day 8–9 | 不再只是执行，开始主动 | 夜班是自己选下来的，不是被安排的 |
| Day 10（终幕） | 重新在场 | 举杯那一刻，就在那里，不需要宣告任何事 |

**写作约束**：不写「治愈」，不写「释怀」，不写任何情绪结论词。变化只能从行为里读出来。

## 四、节奏作为叙事机制

出品一杯饮品需要「打节奏」——这在效率逻辑里没有必要，但这正是铺子的核心逻辑。

对写手的含义：

- **打得好** = 这次接上了，听到了这个人带来的频率
- **打砸了** = 没接上，不是惩罚，是还不了解他们
- **成绩分支（good/ok/bad）**：反映的是「接上了多少」，不是「你厉害不厉害」——角色的反应应该基于他们自身的个性，而不是简单地夸或批评
- **Track Event**：每个 VIP 在某个特定时刻拿出「从未被听见过的那首曲子」——这是信任测试，不是娱乐请求

评分分支写法：每个档次都应该是那个人物特有的反应方式，详见 `05_writing_guide.md`。

## 五、主角过去的渗出时机

主角的背景（AI 系统工程师，被自己参与搭建的系统替代）**永远不被直接说出**，通过以下具体时机渗出：

| 时机 | 渗出方式 |
|------|---------|
| 设备故障 | 下意识说出故障诊断步骤，柚子侧目 |
| 面对老宋（镜像客） | 不解释，只是听；内心节点一刀，极短 |
| 第一次看账本 | 手指在纸上停了一下——不是不会算，是太久没为自己的事情算了 |
| 危机过后，关灯时 | 系统旁白一句收束，类似序章的街灯那句 |
| 夜班第一次（Wings of Silence 时机） | 柚子不在，主角独自在店里，接近自白但仍然没说破 |

## 六、店铺危机细节（第二幕锚点）

危机不是一个人造成的，也不是一个人解决的：

- **房东**：涨租通知，数字是真实的，可以和 VIP 的某条线联动
- **设备**：冷柜彻底罢工（序章里「敲两下」的那台终于撑不住）、榨汁机二次阵亡
- **解决方式**：各客人以各自的能力帮忙——有人出钱，有人出人脉，有人只是来喝了一杯然后什么都没说但第二天危机消了

老板在这时送来一封信，措辞一本正经，建议「多备一台榨汁机」或别的不着调的东西，但信封里夹着一样真正有用的东西（现金 / 联系方式 / 某个信息）。

## 七、叙事节奏约定

| 叙事层 | 规范 |
|--------|------|
| **旁白** | 巨响 / 动作 / 环境变化，不做心理分析 |
| **内心** | 每章 0–1 刀，身体细节，不说结论 |
| **系统** | 每天结尾一句，散文感，过渡结算画面 |
| **订单卡** | 三要素：品名 / 人物特征 / 时间感 |
| **老板信件** | 书信体，不超过 4 句话，荒谬 + 真用 |
| **成绩分支** | good / ok / bad 三档，像嘴碎不像金句 |

执行细则见 `05_writing_guide.md`。
