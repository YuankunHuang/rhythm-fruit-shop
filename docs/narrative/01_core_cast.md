## 柚子

**职能**：前辈 / 现场负责人 / 真正的兜底人

**外形占位**：短发，围裙总系得松，站姿微斜——不是懒，是站了太多年了。
（正式美术待定，暂用现有占位立绘）

**语言特征**
- 句子短，信息量落在动作和具体事上
- 嘴损是工具，不是人设：每次"刻薄"后面都跟着真正有用的事
- 不说废话，不解释为什么这么做——她信任你的时候你能感觉到，但她不会说出来
- 禁用词：总之、其实、不管怎样、没关系（她说没关系的时候是真的有关系）

**弧线**

| 阶段 | 状态 | 标志性行为 |
|------|------|----------|
| 序章–Day2 | 嘴损·测试期 | 出任务、扔信息、走人 |
| Day3–5 | 开始信任 | 留下来多说一句，偶尔停在你身边没有理由 |
| Day6–7（危机） | 裂缝出现 | 第一次正面说"我以为这次真的完了" |
| Day8–9 | 放手 | 把夜班交给你，不再解释 |
| Day10（终幕） | 在场 | 举杯，话不多，但那杯是她主动倒的 |

**禁止处理方式**
- 不写她的"辛酸往事"作大段独白
- 她的软肋通过行为（而不是台词）显形

**序章已定台词风格（参考锚）**
> 「别太信机器，它们比你还爱演。」  
> 「敲了它两下，又是一副天下第一的气势了。」

## 老板

**职能**：远端谜面 / 真正的舞台调度者

**出场方式**：永远不在场，或者在场但从不被指认
- 主要载体：手写便签、书信、偶尔一条旧式短信（没有智能预测，全程手动标点）
- 措辞：**一本正经胡说八道，但落到有用**

**语言特征**
- 书信体，一般不超过 4 句话
- 第一句永远是某种荒谬的"管理圣旨"
- 最后一句永远落到一个具体可操作的事
- 从不问"你还好吗"

**书信（叙事约束）**
- 游戏内书信为**致全体雇员的公开信**。
- 主角尚未搬入店/宿舍前，信内**不描写主角个人住处租金**（可与系统里程碑解耦写法）。

**示范（草稿）**

> 「经查，本店冷柜已满 180 天未做跌落测试。凡是扛得住跌落的东西，才算真正可信。榨汁机已代为购置新滤网一套，放在后厨第三格。另：夜班灯光不足，自行处理。」

**微服私访设计**
- 在某天的日常对话里，有一个来客的行为"太像老板了"
- 但永远不点破——是主角在内心里的一条极短节点，然后话题转移
- 玩家可以自己判断，或者永远不判断

## 你（玩家 / 主角）

**职能**：玩家视角 / 叙事承载体

**说出口的话**
- 简短，多问句，少主动陈述
- 偶尔接不上话（沉默也是一条节点）
- 喜剧感来自落差：别人说得很严肃，你接了一句很平的话

**内心节点规范**（全局执行）
- 全场不超过每章 1 刀
- 必须是身体细节 + 眼前的具体物品，**不写"我觉得"、"也许"、"难道"**
- 不点破前史关键词（AI / 裁员 / 系统 / 优化 / 卖命 等）
- 好的示范：`（内心的节奏吗……）` `（……跑得好快。）`
- 不好的示范：`（这让我想起了以前在公司的日子……）`

**与不同人物的对话基调**

| 对象 | 基调 |
|------|------|
| 柚子 | 接话 > 说话；被问到才答，但答的不含糊 |
| 客人 | 先问需求，偶尔接一两句闲话 |
| 阿往（镜像客） | 听多说少，结尾那句话要能两解 |
| 老板信 | 只有内心旁白，没有"说出口"的回应 |
