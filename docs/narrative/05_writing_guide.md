# 对话风格基准手册

> 供所有日期剧本改写参考。原则来自主创讨论，不得随意简化或绕过。  
> 故事框架与叙事规范见 `01_story_bible.md`，人物详卡见 `02_core_cast.md` / `03_vip_characters.md`。

---

## 核心四原则

### 1. 喜剧的内核是悲剧

不怕写喜剧，越喜剧越好——因为反差越强烈，关键情绪落点就越重。

柚子的早晨越热闹，阿晟的「系统误判四个字比它代表的那件事轻多了」就越有重量。喜剧和悲剧不是两种色调，是同一个杠杆的两端。怎么用好这个杠杆：先把喜剧写真，再把悲剧藏进日常里，不解释，不提示。

### 2. 幽默是恰到好处的尴尬

幽默不是插入一个笑话。幽默是一个时刻——双方都感觉到了，但没人说出来。或者一个人说了，另一个人接不住。或者接住了，但接歪了。这种「歪」是真实的，不是设计出来的。

### 3. 没有人扮演小丑

所有人都是自己，基于自己的动机做事。

柚子的演讲有效，不是因为她在「扮演喜剧角色」，而是因为她**真的这么相信**。她对节奏的信仰是真实的，表达方式是她自己的——幽默感来自她的真诚遇上你的困惑，不是她在表演。

同样：阿晟的精确是他处理世界的方式，不是「严肃角色」的标签。猫小姐用猫的逻辑组织世界，因为她就是这样的人。林小末直接说出不舒服的真话，是因为她还没学会过滤。

**喜剧性来自真实自我碰到外部世界时产生的摩擦，不来自角色扮演。**

### 4. 日常是底色

「看似无意义的日常」才是最重要的剧情底色。

一段关于葡萄冰沙应该多厚的对话，一个关于挂件是不是捡的的含糊，一次关于今天单子好不好出的闲聊——这些不是剧情填充，这些就是故事本身。有了日常的积累，关键剧情才有独特的重量。

**不要跳过日常。不要觉得日常「不重要」。**

## "你"这个角色

### 有什么

- **轻微的推回去**：不是对抗，是真实的不理解或者不确定。「昨天不就是做的厚的吗。」
- **内心旁白**（空白 speaker 的括号行）：幽默和性格的主要出口，也是「恰到好处的尴尬」发生的地方。
- **偶尔歪掉的联想**：在别人说了一句话之后，你想起了别的什么——然后那个联想被打断了，什么都没发生。

### 没有什么

- **不是透明的**：1-3字的纯功能回应（「有。」「好。」「能。」）是以前的写法，要改掉。
- **不是旁观者**：「你」是参与者，你的反应影响对话的节奏和走向。
- **但也不是主导者**：你陪着，不抢戏。不要让「你」比客人说更多。

### 量感参考

参照序章里「你」的密度：镇定擦嘴角（行为旁白）、「精神焕发？」（轻微的推回去）、「那个……柚子。」（有一点笨拙的开口）。这个密度是对的，不要再减。

## 柚子场景（Morning）

### 气质

柚子的喜剧性来自她对自己工作的**真实信仰**，以及她表达这种信仰的方式和你的语境之间产生的落差。她不是在演，她是真的这样。

Morning 场景的节奏：起点是她在评价昨天的状态，然后有一个意外或转弯，然后到她的信仰宣言（每次的主题不同），然后她走了，留下你和那个信仰。

### 功能

- 建立这一天的色调——不是每天都一样热闹，但每天都有柚子自己的样子
- 留下今天的某个细节，可能在后面某处回响（也可能不回响，这是日常的特权）
- 给玩家一个「准备好了」的感觉，然后推向客人

### 不要做的

- 不要让 Morning 变成任务简报——柚子不是 NPC，她在生活里
- 不要每天的 Morning 结构相同——有的天她话多，有的天她在赶事情，有的天她心情不太对但没说

## VIP 对话场景

### 人物第一次出现

- 他们不是来说主题的，他们是来买东西的
- 外形细节要有画面（见 `02_track_vip_map.md` 的外形占位），但不要「列举」，要「捕捉到了」
- 让对话自然地走，不要提前指向什么
- 「你」可以问一个稍微偏的问题，或者注意到一件不重要的事

### 主题「漏出来」的原则

不要让角色直接陈述自己的处境。让主题通过他们说的「别的事」透出来。

- 错误示范：阿晟说「我对算法系统感到愤怒和无力」
- 正确示范：阿晟说「『系统误判』四个字比它代表的那件事轻多了」——然后换话题

### 「恰到好处的尴尬」在 VIP 场景里

- 你说了一句你以为没问题的话，但客人停了一下
- 或者客人说了一句很重的话，然后继续喝饮料，好像什么都没发生
- 或者你和客人同时停住，都不知道接什么，然后其中一个人说了一件不相干的事

## 评分分支

### 结构原则

每个评分档是一个完整的小场景，不只是语气切换。同样的角色，在这个时刻呈现出他们的不同侧面——但不是「开心版」和「失望版」，而是两种真实的可能。

### 好评档（>=88）

客人用一个**只有他才会有**的方式回应。不是简单地夸，而是那个反应本身告诉你他是什么样的人。

示例（阿晟好评）：他按大小排好硬币，数一遍，收进口袋。说「不习惯的话不用理解」。「你」看着那排硬币留下的痕迹——没有理解，但也没有觉得奇怪，就是看了一会儿。

### 差评档（<62）

不是失望，是一种小错位。双方都感觉到了，没有人说。**那个没说出来的是重量。**

示例（阿晟差评）：他说「失准」，停住，把杯子拿走了——没有要求重做，没有多说。那个拿走的动作比「不是批评」四个字更重。

### 共同收尾（after）

分支汇合后，after 里的东西应该对两档都成立——但感觉不完全一样。读者回头看时，会觉得同样的台词在两个情境里各有自己的重量。

## 物件与身体语言

物件是台词的替代品。一个人怎么放杯子、怎么收硬币、怎么把手机屏朝下扣在台面上——这些比他们说「我现在的状态是这样」更真实，也更有画面感。

每段对话里，找**一到两个**属于这个角色的物件或动作。不要解释它，让它在那里。

## 节奏工具

### 加速

你和客人的短句打来打去：

```
林小末：哪门。
你：数学。
林小末：为什么不喜欢？
你：……不知道，就是不行。
```

### 停下来

一个行为描写，或者一个无法回答的问题，或者一个括号内心：

```
他停了一下，像在审阅自己刚才说的词。
（再少就不是冰沙了——但你没说。）
```

### 不要

不要连着三行「xx：一句话。」——中间要插行动或者「你」的反应。不要用节奏均匀的方式告诉读者这是一段「重要的对话」。

## 禁止清单

- **禁止主题标签化**：不要写「你感觉到了他的孤独」。让读者感觉，不要告诉。
- **禁止过度注释行为**：行为描写后面不要跟解释（「他这样做是因为……」）
- **禁止均匀节奏**：不要一行柚子一行你一行柚子。有时候柚子说三行，你一句都没插上。
- **禁止提前揭示**：第一次见面的客人不能泄露他们后面的戏。Day 2 的阿晟不知道那个电话会有什么结果。
- **禁止「意义感」泄漏**：不要让日常对话里某句话带着「这句话很重要」的提示感。就算它真的很重要，也不要提示。
- **禁止解释情绪**：「她有点难过」、「他感到释然」——这些词不存在。情绪在行为里，在停顿里，在那个没说出来的句子里。
