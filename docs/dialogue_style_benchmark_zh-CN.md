# 对白风格基准 · 审定稿（v1）

本文为《节奏鲜果铺》**中文对白文风锚点（v2）**：后续扩写日程、VIP、常客与序章增补时，应先对照本节，再在 [`data/dialogue/prologue.json`](../data/dialogue/prologue.json) 等与 runtime 对齐的 JSON 落盘。

关联：[`docs/narrative/00_story_framework.md`](./narrative/00_story_framework.md)（叙事大纲）、[`docs/narrative/01_core_cast.md`](./narrative/01_core_cast.md)（核心角色设定）、[`data/dialogue/prologue.json`](../data/dialogue/prologue.json)（序章运行时权威源）。

## 1 写作通则（本条为「龙族读者印象」的工程化复述）

| 维度 | 做法 |
|------|------|
| 基底 | **多数台词像真人**：短句、口头语、具体事（钱、课、机器、赶车）。 |
| 升格 | **少数节拍**再上比喻或镜头感（被巨响打断的金句也算升格），**一两句就落回地面**。 |
| 关系戏 | **柚子对你**：嘴损→接得住→托付；喜剧来自**打断、落差**，不是每人每句骈文。 |
| 括号 | **动作 / 巨响 / 小动作**可走 `旁白`，纯内心走神走 **`内心`** 节点（与说出口的话分开）；细节见技术约定。 |

## 2 风格基准场景（剧本文 · 已定稿微调版）

以下为作者提供底稿并经编辑**微调**后的完整定格（用作审美对齐，句式可背不可抄进别作品字面）：

**柚子**  
喂，快收一收，口水流出来了。

**你**  
……（镇定地擦了擦嘴角。并没有口水。）

**柚子**  
脸红什么？

**你**  
精……精神焕发？

**柚子**  
别贫嘴。叫你半天了。我要的柠檬汁呢？

**你**  
那个……柚子。

**柚子**  
怎么了？

**你**  
我们的榨汁机好像坏了。

**柚子**  
那是你刚才「炽热的目光」让它不堪重负了。

**柚子**  
不愧是和机器打过交道的，连望向榨汁机的眼神都能这么深情。

**你**  
哈哈……

**柚子**  
（拍了拍你的肩）没事，榨汁机我来处理。先用手打。第一天上岗，精神点儿。我刚才讲的流程，都记牢了？

**你**  
大概？

**柚子**  
（叹气）

**柚子**  
没事，一步步来，照着指南走。要找自己内心的节奏——用咱们老板的话说，最美的东西光用眼睛不够，还得用心去——

**旁白**  
话没说完，后厨传来「砰」的一声巨响。

**后厨**  
柚——子——

**柚子**  
来了！！

**柚子**  
这里就交给你。学会独当一面吧，少年！

**内心**  
（……跑得好快。）

**内心**  
（内心的节奏吗……）

**学生**  
那个……请问有人吗？

**你**  
有的。需要什么？

**学生**  
一杯柠檬水，少冰。要最「低调」的那款。

**你**  
「最低调」？

**学生**  
对，拜托了，还得留几块钱坐车。

**你**  
包在我身上。话说今天不是周末吗？

**学生**  
周末啊，所以只有两节课。

**你**  
「只」？

**学生**  
你这语气就像没被课表撵着跑过的大人啊～真让人羡慕。

**内心**  
（这小鬼……）

**订单**  
第一单服务 · **柠檬水** · 简单柑橘饮 / 学生赶车 / 二十来秒的事儿

## 3 序章全文（运行时 v1）

与 [`data/dialogue/prologue.json`](../data/dialogue/prologue.json) **逐字一致**（含服务后三分支与共用的扩写）。为维护单一事实源，**不在此重复粘贴全文**，请直接打开该 JSON 或在游戏里走一遍序章；本文件第二节为不可漂移的「关系戏 + 笑点链」锚点（正文以 JSON 历次修订为准，§2 在每次中文版变更后应从 JSON 回抽同步）。
